# Primitive DB project 🚀
 
Учебный проект по созданию консольной реляционной базы данных на Python. Проект разработан с использованием пакетного менеджера `uv` в рамках процедурного подхода. База поддерживает управление таблицами, полный набор CRUD-операций, а также продвинутые механизмы (декораторы и кэширование) и сохраняет структуру в формате JSON.
 
---
 
## 🛠 Технологии и стек
- **Python** 3.12+
- **uv** (управление проектом, виртуальным окружением и зависимостями)
- **Ruff** (статический анализ кода и проверка PEP8)
- **prompt** (удобный интерактивный ввод данных)
- **prettytable** (красивый форматированный вывод таблиц)
- **shlex** (безопасный парсинг аргументов командной строки)
- **json** и **os** (сохранение метаданных и данных таблиц)

## ⚙️ Установка и запуск
 
1. Склонируйте репозиторий на свой компьютер:
   ```bash
   git clone https://github.com/VeraVorozova/project-2_vorozova_M26_555.git
   cd project-2_vorozova_M26_555
   ```
 
2. Синхронизируйте зависимости и создайте виртуальное окружение с помощью `uv`:
   ```bash
   uv sync
   ```
 
3. Запустите приложение в терминале:
   ```bash
   uv run database
   ```

## 📋 Управление таблицами
 
В интерактивном режиме работы программы поддерживаются следующие команды для работы со схемой:
 
- **`create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...`** — создаёт новую таблицу. 
  * *Примечание:* Столбец `ID:int` (первичный ключ) добавляется автоматически в начало таблицы. 
  * *Поддерживаемые типы данных:* `int`, `str`, `bool`.
- **`list_tables`** — выводит список всех созданных в базе таблиц.
- **`drop_table <имя_таблицы>`** — полностью удаляет указанную таблицу (с запросом подтверждения).
- **`info <имя_таблицы>`** — выводит информацию о структуре таблицы и количестве записей.
- **`help`** — показывает справочную информацию по командам.
- **`exit`** — завершает работу программы.

## 🔄 CRUD-операции и работа с данными
 
Для управления записями внутри таблиц используются следующие команды:
 
- **`insert into <имя_таблицы> values (<значение1>, <значение2>, ...)`** — добавляет новую запись с автоматической генерацией ID.
- **`select from <имя_таблицы>`** — выводит все записи таблицы в виде красивой таблицы (`PrettyTable`).
- **`select from <имя_таблицы> where <столбец> = <значение>`** — фильтрует и выводит записи по условию.
- **`update <имя_таблицы> set <столбец1> = <новое_значение1> where <столбец_условия> = <значение_условия>`** — обновляет записи по условию.
- **`delete from <имя_таблицы> where <столбец> = <значение>`** — удаляет записи по условию (с подтверждением).

## ✨ Декораторы и кэширование
 
В проекте реализованы паттерны с использованием декораторов и замыканий:
- **`handle_db_errors`** — централизованная обработка исключений (`KeyError`, `ValueError`, `FileNotFoundError`).
- **`confirm_action`** — фабрика декораторов для безопасного выполнения опасных операций (`drop_table`, `delete`) с запросом подтверждения `[y/n]`.
- **`log_time`** — замер и вывод времени выполнения ресурсоемких операций (`insert`, `select`).
- **Замыкание для кэширования** — ускоряет повторные запросы `select` с помощью внутреннего кэша.
