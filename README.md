# Primitive DB project 🚀

Учебный проект по созданию консольной реляционной базы данных на Python. Проект разработан с использованием пакетного менеджера `uv` в рамках процедурного подхода. База поддерживает управление таблицами и сохраняет структуру в формате JSON.

---

## 🛠 Технологии и стек
- **Python** 3.12+
- **uv** (управление проектом, виртуальным окружением и зависимостями)
- **Ruff** (статический анализ кода и проверка PEP8)
- **prompt** (удобный интерактивный ввод данных)
- **shlex** (безопасный парсинг аргументов командной строки)
- **json** (сохранение метаданных таблиц)

---

## ⚙️ Установка и запуск

1. Склонируйте репозиторий на свой компьютер:
   ```bash
   git clone https://github.com/VeraVorozova/project-2_vorozova_M26_555.git
   cd project-2_vorozova_M26_555
   ```

2. Синхронизируйте зависимости и создайте виртуальное окружение с помощью `uv`:
   ```bash
   uv sync
   ```

3. Запусти приложение в терминале:
   ```bash
   uv run project
   ```

## 📋 Управление таблицами (Доступные команды)

В интерактивном режиме работы программы поддерживаются следующие команды:

- **`create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...`** — создаёт новую таблицу. 
  * *Примечание:* Столбец `ID:int` (первичный ключ) добавляется автоматически в начало таблицы. 
  * *Поддерживаемые типы данных:* `int`, `str`, `bool`.
- **`list_tables`** — выводит список всех созданных в базе таблиц.
- **`drop_table <имя_таблицы>`** — полностью удаляет указанную таблицу.
- **`help`** — показывает справочную информацию по командам.
- **`exit`** — завершает работу программы.

### Пример использования в консоли:

```text
***База данных***
Функции:
<command> create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ... - создать таблицу
<command> list_tables - показать список всех таблиц
<command> drop_table <имя_таблицы> - удалить таблицу

>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

>>>Введите команду: list_tables
users

>>>Введите команду: drop_table users
Таблица "users" успешно удалена.
```
